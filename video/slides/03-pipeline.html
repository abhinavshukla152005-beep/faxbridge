Nothing touches the network.

The image and the text stay in memory. There is no fetch on the ingest or OCR path — the only outbound call is the webhook the user types in.

Confidence is the product.

Each value carries a score from 0 to 1, scaled by the page's median word confidence. Under 0.8 the field is flagged for a human.
